# 密码找回与重置需求

> 日期：2026-09-02
>
> 状态：待评审

## 目标

用户通过已绑定邮箱的一次性验证码设置新密码，不需要已登录会话。

## API

- `POST /api/v2/auth/password-reset-codes`：提交 `email`。无论账号是否存在均返回成功；仅未注销的
  已存在账号会收到真实邮件。
- `POST /api/v2/auth/password-resets`：提交 `email`、`verification_code`、`new_password`。
  成功后不签发 token，客户端须用新密码重新登录。

## 安全与数据语义

- 重置验证码和注册验证码以 `password_reset` / `registration` 用途隔离，摘要计算、数据库行和消费均不能互用。
- 验证码仅保存摘要，6 位数字、10 分钟有效、单次消费，并沿用现有发送冷却、窗口限流与失败次数上限。
- 密码按注册规则校验，以 bcrypt 保存；密码更新和撤销该用户所有有效会话在同一事务中完成。
- 重置邮件使用独立主题与 SES 模板配置 `TENCENT_SES_RESET_SUBJECT`、
  `TENCENT_SES_RESET_TEMPLATE_ID`，模板必须包含验证码、有效期和“非本人操作请忽略”提示。
  未配置时生产环境 fail-closed。
- 流程不得变更用户的邮箱、name、资料、角色、封禁状态、内容或社交关系。
